# hybrid/ — 融合检索策略（设计位）

本目录为**契约文档位**，不包含实现代码。企业级 RAG 检索侧的融合检索（初排 + 重排）实现是后续里程碑。

## 设计意图

- 基座语料 + 增量语料双路召回，按时间/来源加权融合，再进重排。
- 初排（向量检索 embedding + ANN）负责召回，重排（BM25 / 交叉编码器）负责精排。
- 参数（权重、TopK、候选数）见 `config/bline.yaml`，本目录只定义"融在哪个环节、输什么、收什么"。

## 位置（占位）

- `fuse.md`（规划）：融合策略与口径说明，列输入（两路候选集）、输出（融合排序列表）、可观测指标。
- 无 `.py` 实现。核心检索代码不在此处。
